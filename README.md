## 🖥️ Cara Menjalankan Website

1. **Cara Langsung:**
   - Cukup buka file `index.html` dengan klik ganda di browser Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll.).

2. **Menggunakan Web Server Lokal:**
   - Klik ganda file `start_server.bat`, browser akan otomatis terbuka di `http://localhost:8080`.
   - Atau via terminal PowerShell / CMD di folder proyek:
     ```bash
     python -m http.server 8080
     ```
     Lalu buka `http://localhost:8080` di browser.

## 🌐 Cara Publikasi / Deploy Online (Gratis)

Website ini adalah murni HTML, CSS, dan JavaScript statis tanpa dependensi server backend, sehingga dapat di-hosting secara gratis dan sangat cepat di:
1. **GitHub Pages** (Gratis selamanya, cukup push ke repository GitHub).
2. **Vercel** / **Netlify** (Drag and drop folder ini langsung aktif dengan custom domain).
3. **cPanel Web Hosting** (Upload semua file ke dalam folder `public_html`).
